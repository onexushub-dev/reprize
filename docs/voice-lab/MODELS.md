# Voice detector model files — provenance and licenses

The files the voice keyword detector ("salvar", pt-BR) ships, where each comes from, its license and how it is
built. **No file here goes into a store build before Victor approves this page** (plan Task 1, step 8).

Built by `lab/tools/export_detector.py` (`fetch` → `build` → `mac`). Lab results: `2026-11-23-voice-trigger-field-test.md`.

| File (version `salvar-v1`) | What it is | Source | License |
|---|---|---|---|
| `detector.json` | Pipeline numbers (rates, sizes, threshold 0.95, 2 in a row, 1.5 s refractory) | Ours | Ours |
| `mel_filterbank.bin` | 257×32 mel filterbank (float32 LE) | Generated by us with torchaudio `melscale_fbanks` (slaney scale + norm, 60–3800 Hz), asserted equal to openWakeWord's `melspectrogram.onnx`. The Hann window and FFT are computed in our code | torchaudio: BSD-2-Clause; the numbers are a mathematical transform we generate |
| `classifier.bin` | "salvar" classifier, 1536 → 128 ReLU → 1 logistic (model M4) | Trained by us in `lab/tools/detector_v4.py` on our own recordings and noise | Ours |
| `voice_embedding.tflite` (Android) | 96-d speech embedding every 80 ms | openWakeWord v0.5.1 `embedding_model.tflite`: their re-implementation of Google's speech embedding | Google speech_embedding (TF Hub): Apache-2.0; openWakeWord code: Apache-2.0 |
| `voice_embedding.mlmodelc` (iOS) | Same embedding, Core ML | Converted by us from openWakeWord v0.5.1 `embedding_model.onnx` (same weights), checked against the ONNX to < 1e-3 | Same as above (Apache-2.0) |

**Not used:** openWakeWord's pretrained wake-word models, which are CC BY-NC-SA 4.0 (non-commercial).

**Approved by Victor on 2026-11-24, as is (the openWakeWord version of the embedding).** Earlier open point: openWakeWord states that Google's speech embedding is Apache-2.0. Their re-implementation
of it carries no separate license statement, beyond the repository's Apache-2.0. If Victor wants zero doubt, the
alternative is to convert Google's original TF Hub model ourselves (same architecture, same license) and re-check
parity. The app's open-source licenses list must name the Apache-2.0 notice for the embedding either way.

## salvar-v2-rc1 (the app's model behind the Diagnóstico switch, 2026-11-25)

Same pipeline, embedding and filterbank as `salvar-v1`; a new classifier (1536 → 256 ReLU → 1 logistic) that waits
for the word to end (~0.25 s later than v1) and was also trained on public speech. Built from
`lab/tools/models/clf_v8_h256_s1.pkl` (`lab/tools/exp_v8.py`); compared with v1 in `lab/tools/eval_range.py`.
iOS only for now (`ios/Models/voice/salvar-v2-rc1/`).

Training data (used only to train; no audio from any of them ships in the app, only the learned weights):

| Data | Used for | License |
|---|---|---|
| Reprize's own recordings (Victor, Eliane, Yasmin, Sara; courts, crossfit, home) | "salvar", noise and similar words | Ours, with the speakers' consent |
| MLCommons Multilingual Spoken Words Corpus, Portuguese (Mazumder et al., 2021) | "salvar" and similar words (salvador, saltar, salto…) | CC BY 4.0 (credit given here) |
| Mozilla Common Voice 27.0, Portuguese | similar words and everyday speech from 3,600+ speakers | CC0; not redistributed; no attempt to identify speakers |
| Piper TTS pt_BR voices cadu, jeff, faber (datasets CC0) and edresson (TTS-Portuguese-Corpus, CC BY 4.0) | synthetic "salvar" and similar words | Piper: MIT; voices as stated |
